# Last Ticket

Web de presentación de **Last Ticket**, la app de entradas de teatro de último momento para CABA y GBA (Rush y Lottery).

- `index.html`: la presentación, con efectos al hacer scroll y la app funcionando en un celular para recorrer el flujo del servicio.
- `app.html`: la demo de la app (abrila sola desde el celular y agregala a la pantalla de inicio).

Datos: encuesta Last Ticket (n = 404), entrevistas en profundidad y planilla de medios del equipo. Las obras y salas de la demo son de ejemplo.
